### ⚡ Technical Highlights

* **Cycles & Eevee Next Render Engines:** Hardware-accelerated path tracing and real-time PBR viewport rendering pipelines with OptiX/HIP support.
* **Geometry Nodes Pipeline:** Advanced procedural modeling, instancing, and asset distribution system built on multithreaded evaluation graphs.
* **Python & C++ API Integration:** Robust `bpy` scripting wrappers and native extension hooks for custom pipeline automation and tool integration.
* **Physics & Simulation Engine:** High-performance cloth, rigid body, smoke, fluid, and particle dynamics solver architecture.
* **Sculpting & Retopology Toolkit:** High-poly multiresolution mesh editing, dynamic topology brushes, and advanced UV unwrapping pipelines.
